# Kernel v19 确认性测量方案 v2（设计稿，2026-09-28，待批准；本稿取代 v1）

状态：设计稿。v1 因两个执行阻塞被 owner 驳回：(1) 同一身份仅支持一次
preflight（回执存在即拒，`benchmark_runner.py:937`）与一次固定 selection 的
run（subset marker 绑定单一选择，`:627`），四段分跑不可行；(2)
`ManifestCell.repeat_index` 硬上限 3（`benchmark_manifest.py:291`），每场景
8 次重复无法按 v33/v34 配方生成。v2 按真实机制重写：**身份数量、重复映射、
回执范围、跨段停止窗口与主次指标写实**。本稿不授权冻结或执行；暂不改 prompt。

## 1. 身份与分块（4 身份，BAAB 块序）

- 四个新身份，构造配方与 v33/v34 相同（**四份清单各自登记全部四个新 ID**
  → X → freeze → Y → 检出门）；不复用 v33/v34（其回执/subset 状态已固化）。
- 执行序：**B1 → A1 → A2 → B2**（A=旧 v18 对照，B=新 v19 候选），块序
  **BAAB**。每臂各占一个早块与一个晚块，平衡执行顺序；这是块序平衡，**不
  宣称排除时间混杂**。
- 每身份 **恰好一次 preflight + 一次 run**，selector 即其段，首用即唯一使用，
  不触碰回执/subset 限制。

## 3. 回执范围与跨段停止窗口（写实）

- 每身份的 preflight 回执与 subset marker 只覆盖本段 selector；跨段无产品级
  状态。**产品内滚动窗口**只在单段 run 内累计：14 格段可触发（≥12 终态），
  10 格段不足 12 格、按合同不会触发——如实声明，不谎称全程防护。
- **跨段人工门（仅段间检查，不提供逐格跨段保护）**：每段结束后，把已完成
  各段的模型 backed 终态**按实际执行顺序合并，只取最后 12 格**；满 12 格且
  其中 ≥10 未通过 → 整个实验停止。不足 12 格不停（与产品窗口同口径），该门
  不在段内逐格生效。
- **整体停止事件（任一发生即停，不启动后续段）**：任一段 preflight 失败、
  RUN_SETUP_ERROR、恢复失败（ENVIRONMENT_OR_RECOVERY_FAILURE）、身份/归档
  异常、GATE_INTERNAL_ERROR>0。段间复测 F0 与环境（Docker/子模块/porcelain）。

## 4. 主次指标（端到端为主；成对排除仅辅助）

- **主指标（主分母）**：端到端整格通过（含传输失败格）——与 v33/v34 相同口径。
- **辅助口径（仅敏感性）**：沿用 owner 371441b 方法——任一侧格被判定
  transport-failed，则**成对移除**该对后计数；transport-failed 的判定**必须有
  trace `transport_diagnostic=CONNECTION_ERROR|TIMEOUT`**，MODEL_ERROR 无该
  诊断不判传输；metrics requests=0 不代表未发请求。两个口径同时呈现，禁止
  混用样本集合比较。
- **结果不可判条件（预登记）**：transport-failed 对超过全部对的 25%（>6 对）
  → 本轮"不可判"，仅报事实。
- **机会格执行率（描述性指标，本轮不作为晋级硬条件）**：
  - 目标关系**只从当时公开证据确定**（该次提交拟确认根因与所依据 profile 的
    关系），不以私有正确答案回填。
  - 机会判定：从每次模型请求前缀（该请求构建时的控制器账本）**按序扫描，取
    首次同时满足以下四条件的时点，每 run 最多记一次**：已接受目标关系
    profile、同关系 schema 未采、schema 工具启用且关系在 provable 白名单内、
    无同参调用或拒绝收据。
  - 结果 = 从该首次机会时点到终态是否成功完成同关系 schema 采集。
    **分类**：首次机会时点前 schema 已采齐 → 单列"提前满足"，不计未执行；
    机会时点预算不足以容纳核对+仍需决定性取证+最终提交（按公开前缀人工
    复核）→ 单列"预算剔除"；run 在终态前中断 → 单列"run 中断"。
  - 执行率 = 成功采集数 ÷（首次机会开放的 run 数），**描述性呈现**，报告
    原始分子分母；分母为 0 的（臂×场景）不计算，只报计数。不作为晋级条件；
    主判据仍是整格通过与对照不退化。
- **早晚块对比（分口径成功率差，样本数完整报告）**：对每个场景 s 分别计算
  `Δearly_s = B 早段成功率 − A 早段成功率` 与 `Δlate_s = B 晚段成功率 −
  A 晚段成功率`（成功率为该块内该场景 PASSED 格数 ÷ 格数；对照早块每臂每
  场景仅 1 格、晚块 2 格，目标两块各 3 格），连同各自样本数完整呈现。该
  极小样本检查**只是时间顺序嫌疑标记，不是时间漂移的证明**。
  - 反转条件（显式）：`Δearly_s ≥ 0 且 Δlate_s < 0 且 (Δearly_s − Δlate_s)
    ≥ 0.5` —— 任一场景满足即标记"时间顺序嫌疑"并**不晋级**。
  - 未触发反转条件时，该检查不产生晋级后果，只随报告完整呈现。
- **完整性前置**：48 格未全部终态、或任一配对缺失（含 transport-failed 对——
  排除只影响主/辅计数口径，不改变完整性要求）→ 不得晋级，结论
  "不完整/不可判"。
- **晋级条件（预登记，从严）**：在完整性前置通过且 transport-failed 对 ≤6 的
  前提下——主指标目标组 B−A ≥ 3（分母 12）且 dup_a/orphan_a 分别不降；
  **主指标对照组 B ≥ A（不放宽为 A−1）**；辅助口径方向一致（B ≥ A）；无场景
  触发上述反转条件。机会格执行率本轮为描述性指标，不进入晋级判定。任何一条
  不满足 → 混合/负面结论，不晋级、不追加样本。
- 取舍声明：主指标端到端意味着传输失败计入臂内结果（对先跑的 B1 可能不利），
  辅助口径吸收该噪声但不动摇主判读；两者矛盾时以主指标为准并如实报告矛盾。
