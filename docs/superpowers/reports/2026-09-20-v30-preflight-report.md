- 证明：provider 的 chat completion 面可返回 HTTP 500；该错误可被归档机制完整归因
  （M21/M23 的设计目标达成）。
- 不证明：500 的服务端根因（网关/上游/容量——归档不携带服务端错误体，按脱敏纪律不携带）；
