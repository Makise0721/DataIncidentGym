- 行为侧（未观察到变化）：p1-formal-v18 三格测量（协议运行前冻结）中，seq19 两张 history 收据、seq44 的 schema(raw_orders) 收据均未取得；按冻结实现与调用轨迹重建，相关候选应已进入每次请求的 ledger（离线重建，非逐请求 wire 留档，不能证明模型注意或理解了候选）。停止依据是漏探针本身，模型为何不选择探针原因仍未确定，本轮不再要求进一步证明。

## 3. 收尾决定

- **保留当前实现与冻结证据**：投影代码留在 controller（`p1.controller.v18`）中，不回滚——本轮结果不足以要求回滚；v18 清单、三格 run 产物与本报告链全部保留。
- **不再为该投影投入**：不追加提示微调，不安排新的三格测量，不启动 v19。评估报告 §7 预设的停止条件（"该投影若不能改善选择，不再以'再加一句提醒'作为默认下一步"）就此兑现。
- **已知能力限制**：完整弃答规划——在预算内取得决定性收据、完成缺口声明并通过 evaluator——仍是当前模型的已知能力限制，如实记录，不以继续提示修补的方式掩盖。
- **不回改历史**：评估、协议与测量报告均保留原判据与措辞修订痕迹，不改写已冻结清单或产物。

## 4. 未来方向的立项边界

自动探针或确定性收据规划若以后要做，**不是本实验的延续**：它们改变"谁决定探针必要性"的边界，涉及公开任务合同、预算与验收门禁的调整，应作为另一个架构决策重新立项，单独论证范围、成本与验收方式后再实施。
