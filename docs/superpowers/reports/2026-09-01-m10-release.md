## 首次失败与环境边界

首次 M10 矩阵失败中包含一个已确认并修复的产品缺陷：不可观测订单历史的 Kernel probe provenance 约束过窄，导致合法的 `RELATION_HISTORY` 查询被拒；修复已包含在 `1b5cab8` 与最终收窄提交 `ae94dbc`。

其余 Windows 失败没有 Python 或业务断言证据，属于本机 dbt/Python native 稳定性未验证：最终 Windows 单次矩阵为 `20 passed, 6 failed`，其中 4 格为 `INITIAL_RESET_FAILED`，2 格在 `RECOVERY_HEALTHY` 门失败。未重试、未修改产品代码、未把这些格标记为通过；Ubuntu exact-HEAD CI 已验证同一提交的 `26/26`。
