# 离线策略回归方案（草案，待所有者选定干预项）

- 日期：2026-09-20。状态：**草案；所有者选定干预项后再实施。**
- 依据：质量基线（[报告](../reports/2026-09-20-quality-baseline-report.md)，已通过独立复审）显示
  两批 31 格的失败集中在三轴：采集完整性、逐 claim 引用、缺口声明（外加 v30 新增 3 例
  `wrong_abstention`）。所有者边界：以归档机制做**离线回归**；不把私有
  required_evidence_types / 缺口矩阵灌进模型；重算已有答案定位缺陷但**不证明**新策略更优——
  效果须经另行授权的有界真实验证，再进入新身份测量。

## 1. 回归语料与机制（全离线，无模型调用）

- **语料**：两批 31 个终态格的评分包与归档（`.dig/scoring-inputs/`、`artifacts/`），加上所有者
  反事实实验中已验证的 4 个"可修复形态"内存变体（8 补主体、9/13 补引用、12 删多报缺口）；
  变体须以构造器重建为可校验样本（记录来源与变换），不改原归档。
- **两类回归对象**：
  - **harness 侧控制逻辑**（提交门、拒绝码、预算/重试语义）：直接以语料**重放**——门对
    31 个归档诊断逐个判定，期望拒绝/接受集合与基线缺陷形态精确对齐（可对抗化：篡改样本须被拒）。
  - **模型侧变更**（提示词与策略指令）：离线只能验证**身份与合同**（提示摘要/策略身份更新、
    不泄漏私有合同、预算与工具 schema 不漂移），**效果不可离线证明**，须留待有界真实验证。
- 私有合同只出现在 harness 侧执行与离线核对；模型可见面永远只有固定拒绝码与通用指导。

## 3. 验收阶梯（不跳级）

1. **离线回归**（本节机制）：I1/I2 对语料重放精确对齐缺陷形态；全部既有门禁与合成测试通过；
   改动不触评分、不触归档、不触冻结清单。
2. **有界真实验证**（另行授权）：小规模、有界次数的真实运行，检验拒绝码出现率与后续修复行为；
   以编码器/控制器可见的计数为准。
3. **新身份测量**（另行授权）：冻结新清单后按既有测量协议进行，与两批基线**分离报告**
   （批次、场景、策略、前缀重叠关系如实标注；不得当作独立样本或能力水位）。

## 4. 边界

- 本轮不改评分、不改归档、不重跑、不联网、不动冻结清单；I1/I2 的拒绝码集与预算语义变化
  在实施 spec 中细化并经审计。
- 若所有者只选 I1+I2，I3 推迟；若要求先做 I3，则其效果永远只能由第 2/3 步回答。
